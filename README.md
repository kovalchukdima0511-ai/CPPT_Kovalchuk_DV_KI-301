# Кросплатформні засоби програмування

**Ковальчук Дмитро Володимирович, група КІ-301 · варіант 12 «Розсадник рослин»**

Наскрізний продукт курсу: від Maven-проєкту з CSV-звітом (ЛР №1) до параметризованого сховища з рефлексивним CSV-експортом (ЛР №5) і Python-застосунку з ООП-моделлю (ЛР №7). Кожна лабораторна — окрема папка, яку можна відкрити у VS Code через **File → Open Folder**.

| ЛР | Папка | Тема | Версія / тег |
|---|---|---|---|
| 1 | [lab-01](lab-01) | Maven-проєкт, CSV, звіт | v1.0.0 |
| 2 | [lab-02](lab-02) | Класи, record, інкапсуляція | v1.1.0 |
| 3 | [lab-03](lab-03) | Спадкування, інтерфейси, поліморфізм | v1.2.0 |
| 4 | [lab-04](lab-04) | Stream API | v1.3.0 |
| 5 | [lab-05](lab-05) | Repository&lt;T&gt;, анотації, рефлексія, CSV-експорт | v1.4.0 |
| 6 | [lab-06](lab-06) | Обробка даних засобами Python | v1.5.0 |
| 7 | [lab-07](lab-07) | ООП-обробка даних у Python | v1.6.0 |

Вимоги: JDK 17+ (Temurin), Python 3.11+, VS Code з *Extension Pack for Java* і *Python*.

Предметна область: рослина має вид, вік (роки), висоту (см), ціну (грн) і періодичність поливу (дні). Контрольні дані — `lab-0N/data/input.csv`.

CI (GitHub Actions, `.github/workflows/ci.yml`) збирає та тестує всі лабораторні на Ubuntu, Windows і macOS, публікує JAR- і wheel-артефакти.
